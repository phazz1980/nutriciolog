Политика конфиденциальности

Дата обновления: 5 октября 2026 года.

«Мой нутрициолог» помогает вести дневник питания, воды и веса. Эта политика объясняет, какие данные используются приложением и для чего.

Какие данные обрабатываются

При входе через Google приложение получает базовые сведения, доступные в аккаунте: идентификатор пользователя, адрес электронной почты, имя и фотографию профиля. Пользователь также может самостоятельно ввести данные профиля, записи дневника, воду, вес, продукты и параметры блюд.

Где хранятся данные

Для вошедших пользователей данные синхронизируются в Firebase (Google) в личном разделе, доступном только этому пользователю по правилам Firebase. Без входа данные могут храниться локально в браузере устройства. Пользователь может удалять отдельные записи дневника в приложении.

ИИ-советы и фотографии

Для соблюдения месячного лимита ИИ в Yandex YDB отдельно хранятся идентификатор аккаунта Firebase, календарный месяц и число принятых запросов. Для оценки расходов дополнительно сохраняются дата UTC, случайный идентификатор запроса, оценочная сумма в USD и признак неполных данных. Учёт общий для всех устройств аккаунта; вопросы, фотографии и записи дневника в эту таблицу не записываются. История счётчиков и оценок не удаляется автоматически; запросить удаление можно по контактному адресу ниже.

По явному действию пользователя текст вопроса, название блюда, порция или выбранная фотография блюда могут быть отправлены через защищённый сервер приложения к подключённому ИИ-провайдеру для формирования совета или оценки пищевой ценности. Фотография используется только для этого запроса и по умолчанию не сохраняется в Firebase. ИИ не добавляет блюда в дневник автоматически: сохранение подтверждает пользователь.

Передача и защита

Для работы входа, синхронизации и ИИ-функций данные передаются соответствующим сервисам Google Firebase и ИИ-провайдеру. Секретные ключи ИИ не передаются в браузер. Не вводите в поля приложения лишние персональные или медицинские сведения.
